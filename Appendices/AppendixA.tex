\subsection{Supabase Edge Functions}

Üç adet Deno tabanlı Edge Function vardır. Tümü \texttt{POST} metodu, \texttt{Authorization: Bearer <jwt>} başlığı ve \texttt{application/json} içerik tipi ile çağrılır. Yanıtlar yapılandırılmış JSON formatındadır.

\begin{table}[H]
\centering
\caption{Edge Function uç noktaları}
\label{tab:edge_fns}
\small
\begin{tabular}{|l|p{0.50\textwidth}|}
\hline
\textbf{Edge Function} & \textbf{Görev / Girdi--Çıktı} \\
\hline
\texttt{POST /functions/v1/analyze-health-data} &
Çoklu kipli AI analizi. Girdi: \texttt{\{ type, ... \}} -- \texttt{type} alanı şunlardan biri: \texttt{food-image}, \texttt{blood-test}, \texttt{document}, \texttt{medical-photo} (alt türler: \texttt{urine}/\texttt{stool}/\texttt{tongue}/\texttt{eye}/\texttt{skin}), \texttt{voice-entry}, \texttt{voice-food}. Çıktı: tipe göre yapılandırılmış JSON. \\
\hline
\texttt{POST /functions/v1/generate-chat-response} &
RAG chatbot 8 aşamalı pipeline. Girdi: \texttt{\{ conversationId, message \}}. Çıktı: \texttt{\{ content, citations[], suggestedFollowUps[], isHighRisk, model, latencyMs \}}. \\
\hline
\texttt{POST /functions/v1/generate-health-profile} &
Sağlık profili oluşturma. Girdi: \texttt{\{ userData, todayFood, todayWater, recentActivities, todaySleep, recentBlood \}}. Çıktı: \texttt{\{ bmi, bmr, tdee, bodyFatEstimate, healthScore, riskFactors, strengths, improvementAreas, nutritionPlan, exercisePlan, sleepRecommendation, supplementRecommendations, aiSummary \}}. \\
\hline
\end{tabular}
\end{table}

\subsection{Önemli SQL Şema Tanımları}

\paragraph{\texttt{scientific\_source\_chunks} (RAG vector tablo):}
\begin{itemize}
\item \texttt{id uuid PK}, \texttt{source\_id uuid FK $\to$ scientific\_sources}, \texttt{chunk\_index integer}, \texttt{section text},
\item \texttt{content text NOT NULL}, \texttt{token\_count integer}, \texttt{embedding extensions.vector(1536)},
\item \texttt{keywords text[]}, \texttt{language text}, \texttt{created\_at timestamptz}.
\item İndeks: \texttt{idx\_chunks\_embedding using ivfflat (embedding extensions.vector\_cosine\_ops) with (lists = 50)}.
\end{itemize}

\paragraph{\texttt{rag\_query\_logs}:}
\begin{itemize}
\item Kullanıcı sorgusu, getirilen parça kimlikleri (\texttt{retrieved\_chunk\_ids uuid[]}), benzerlik skorları (\texttt{similarity\_scores numeric[]}),
\item Kullanılan bağlam blokları (\texttt{context\_blocks\_used text[]}), model adı, gecikme (\texttt{latency\_ms integer}).
\end{itemize}

\paragraph{\texttt{daily\_health\_logs}:}
\begin{itemize}
\item Bileşik benzersizlik: \texttt{UNIQUE(user\_id, date)}.
\item Varsayılan hedefler: \texttt{calories\_target=2100}, \texttt{protein\_target=180}, \texttt{water\_target=2400 mL}, \texttt{steps\_target=10\,000}, \texttt{sleep\_target=480 dk}.
\end{itemize}
